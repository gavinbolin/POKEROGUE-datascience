Farm Item Priority

How this list works. Drag cards to reorder; higher on the list = picked first. Rarity always wins first: the tier comes from the reward card itself (Master > Rogue > Ultra > Great > Common), so this order decides between items of the same tier. An item can't be dragged into another tier; instead use its “at least” dropdown to lift it (e.g. candy counts as at least Ultra). Pinned rules beat every tier. Cards in Junk lose to any real item whatever their tier, and the farm rerolls when the best card is junk. Purple badges are conditions: the same item can appear several times, and the first card whose condition is true is the one used (that check order is fixed and isn't changed by dragging). Hover/expand for notes. Saving backs up the old file and the farm reloads it automatically.
